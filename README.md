# Práctica Python - Manipulación básica de datos

Este proyecto contiene ejercicios básicos de Python orientados a la manipulación de datos

## Contenidos

- Variables y tipos de datos
- Listas
- Bucles y condicionales
- Diccionarios
- Funciones
- Operaciones estadísticas básicas

## Estructura

- `practica_python.ipynb`: notebook con los ejercicios y sus resultados.
- `README.md`: descripción del proyecto.

## Objetivo

Consolidar conocimientos básicos de Python antes de comenzar a trabajar con librerías de análisis de datos como Pandas y Scikit-Learn.
